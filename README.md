# Bike & Car Shop

A simple inventory management system for a bike and car shop.

## Features

- Add bikes and cars to inventory
- Remove vehicles by ID
- List all inventory
- Filter by vehicle type
- Vehicle information display

## Usage

```bash
npm start
```

## Structure

- `src/models/` - Vehicle classes (Vehicle, Bike, Car)
- `src/services/` - Shop management service
- `src/index.js` - Demo application
